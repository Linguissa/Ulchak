# Como publicar esta versão no GitHub

1. Baixe e extraia `Zeus-da-TI-2.0.zip`.
2. Abra o repositório `Linguissa/Zeus-da-TI` no GitHub.
3. **Recomendação:** crie uma branch nova (por exemplo, `docs/zeus-2.0`) antes de substituir arquivos.
4. Compare o conteúdo antigo com esta versão. Preserve apenas material antigo que esteja autorizado, atualizado, sem dados sensíveis e tecnicamente revisado.
5. Envie os arquivos da pasta `Zeus-da-TI-2.0` para a raiz do repositório, mantendo as pastas.
6. Confira a prévia do `README.md` e aguarde o workflow `Quality checks` concluir.
7. Revise o diff e só então abra um pull request ou faça merge, conforme o processo da equipe.

Para testar localmente: `python scripts/check_repo.py`.

Esta entrega não foi enviada automaticamente ao GitHub. Ela é um pacote de arquivos pronto para revisão e publicação.
