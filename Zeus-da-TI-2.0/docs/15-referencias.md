# 15 — Referências oficiais

> Consulte sempre a versão vigente na fonte oficial. As versões abaixo foram verificadas em 16 de novembro de 2026; projetos em desenvolvimento podem mudar sem aviso.

## Metodologia e avaliação

- [NIST SP 800-115 — Technical Guide to Information Security Testing and Assessment](https://csrc.nist.gov/pubs/sp/800/115/final). Guia de planejamento, execução, análise e mitigação de avaliações técnicas.
- [MITRE ATT&CK](https://attack.mitre.org/). Base de conhecimento de táticas e técnicas observadas em atividades adversárias. Use como referência de modelagem e detecção, não como autorização para reproduzir técnicas.
- [FIRST CVSS](https://www.first.org/cvss/). Especificação e recursos para avaliação de severidade técnica.
- [MITRE CWE](https://cwe.mitre.org/). Catálogo de fraquezas comuns de software.
- [MITRE CVE](https://www.cve.org/). Programa e identificadores de vulnerabilidades divulgadas.

## Aplicações web

- [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/). A página do projeto lista a versão estável 4.2 e informa que a 5.0 está em desenvolvimento.
- [OWASP Application Security Verification Standard](https://asvs.owasp.org/). A página oficial apresenta ASVS 5.0.0 como versão estável.
- [OWASP Top 10](https://owasp.org/www-project-top-ten/). Documento de conscientização sobre riscos comuns de aplicações web.

## Competição

- [WorldSkills International](https://worldskills.org/). Consulte a página oficial da ocupação Cyber Security, a descrição técnica e o Test Project da edição específica.
- [WorldSkills — Skills Competitions](https://worldskills.org/what/competitions/). Informações institucionais sobre competições.

## Como citar no relatório

Inclua nome, versão/edição, endereço e data de consulta. Não copie trechos extensos. Ao referenciar um requisito do WSTG ou ASVS, registre o identificador e a versão correspondente.
