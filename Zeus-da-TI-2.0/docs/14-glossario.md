# 14 — Glossário

| Termo | Significado |
|---|---|
| Ativo | Recurso de informação ou tecnologia relevante para o exercício. |
| Autenticação | Processo de verificar uma identidade. |
| Autorização | Decisão sobre o que uma identidade pode fazer. |
| Blue Team | Equipe focada em defesa, monitoramento e resposta. |
| CVE | Identificador público de uma vulnerabilidade divulgada. |
| CVSS | Sistema padronizado para expressar severidade técnica. |
| CWE | Catálogo de tipos comuns de fraquezas de software. |
| Evidência | Registro que sustenta uma observação ou conclusão. |
| Falso positivo | Alerta que não corresponde a uma condição vulnerável aplicável. |
| Hardening | Redução de riscos por configuração e controles seguros. |
| Hipótese | Explicação possível que ainda precisa ser confirmada. |
| IOC | Indicador de comprometimento, como artefato associado a atividade maliciosa. |
| Menor privilégio | Conceder somente as permissões necessárias à função. |
| OSINT | Inteligência obtida de fontes abertas. |
| Pentest | Avaliação técnica de segurança dentro de escopo definido. |
| Purple Team | Colaboração entre equipes ofensivas e defensivas. |
| Red Team | Simulação autorizada de ameaça para avaliar controles e resposta. |
| Reteste | Nova verificação após uma correção. |
| ROE | Regras de engajamento (Rules of Engagement). |
| Escopo | Limites de ativos, ações, tempo e dados permitidos. |
| WSTG | OWASP Web Security Testing Guide. |
| ASVS | OWASP Application Security Verification Standard. |
